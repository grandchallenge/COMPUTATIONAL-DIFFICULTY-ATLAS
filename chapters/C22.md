## Question: are all undecidable problems equally inaccessible?

Whether a program halts on one input differs from whether it halts on every input. The first asks for a finite event; the second ranges over infinitely many inputs.

## Section 1 — Unbounded quantifier blocks

For a decidable predicate $R(x,y_1,\ldots,y_k)$ on natural numbers, a $\Sigma^0_k$ set is expressible with $k$ alternating unbounded quantifier blocks starting existentially; $\Pi^0_k$ starts universally. Finite tuples may be coded as one integer. Write $\Delta^0_k=\Sigma^0_k\cap\Pi^0_k$. Unlike C09, these quantifiers range over all natural numbers, not polynomial-length witnesses.

## Section 2 — Halting is existential

Let $H(e,x,t)$ decide whether machine $e$ halts on input $x$ within $t$ steps in an effective enumeration. Then

$$
(e,x)\in\mathrm{HALT}\iff\exists t\,H(e,x,t).
$$

HALT is $\Sigma^0_1$-complete by C21; its complement is $\Pi^0_1$-complete. Recognizable sets are exactly $\Sigma^0_1$: search witnesses to a decidable predicate, or encode finite acceptance. Their intersection with co-recognizable sets is exactly the decidable sets by dovetailing, so $\Delta^0_1$ is the decidable class.

## Section 3 — Totality

Define TOT as indices of machines halting on every natural-number input:

$$
e\in\mathrm{TOT}\iff\forall x\,\exists t\,H(e,x,t).
$$

For hardness, take any $A=\{a:\forall x\,\exists y\,R(a,x,y)\}$ with decidable $R$. Generate code which on input $x$ searches $y$ in order until $R(a,x,y)$ is true, then halts. The code generator is total computable; its output is total iff $a\in A$. Thus TOT is $\Pi^0_2$-complete under computable many-one reductions.

## Section 4 — Degrees and the jump

Mutual Turing reducibility defines Turing degrees. Decidable sets have least degree $\mathbf0$. The jump $A'$ is the set of indices of oracle-$A$ programs halting on their own index. If an oracle-$A$ decider for $A'$ existed, construct a program that halts on its own index exactly when predicted not to halt. Contradiction. Conversely $A\le_T A'$ by compiling an oracle query into code halting iff its answer is yes. Thus each jump strictly increases degree.

Post's theorem: for $k\ge1$, $\Sigma^0_k$ consists of sets recognizable relative to the $(k-1)$st jump of the computable degree; $\Delta^0_{k+1}$ consists of sets decidable relative to the $k$th jump. The hierarchy is strict. The degrees need not be linearly ordered.
