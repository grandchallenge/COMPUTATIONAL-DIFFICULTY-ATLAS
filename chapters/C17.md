# C17 — Parameterized Complexity: Which Part of the Input Is Difficult?

**Status:** Editorial candidate; review and figures pending.
**Prerequisites:** C02, C03, C05, C06.

## Question: what if the difficult part of an enormous input is small?

A network has a million vertices but we seek at most five vertices touching every edge. Enumerating five-element subsets may be prohibitive. Can we make the exponential cost depend only on five?

## Section 1 — Two size measures

A parameterized decision problem is a language of pairs $(x,k)$, with nonnegative integer parameter $k$. For $n=|x|$, FPT allows time $f(k)(n+1)^c$ for computable $f$ and constant $c$ independent of $k$. XP allows $f(k)(n+1)^{g(k)}$ for computable $f,g$. FPT is contained in XP. A bound $n^k$ is XP, not an FPT guarantee. Polynomial time on each fixed slice does not alone give uniform FPT.

## Section 2 — Vertex cover: a branching proof

For an explicit undirected simple graph $G$, ask if a set of at most $k$ vertices meets every edge. Reject negative budget; accept an edgeless graph; reject budget zero with an edge. Otherwise choose edge $uv$. Every cover contains $u$ or $v$. Recurse on $(G-u,k-1)$ and $(G-v,k-1)$, accepting if either accepts.

Induction proves correctness: every cover supplies one branch; every reduced cover extends by the chosen endpoint. At most $2^{k+1}-1$ recursive nodes each cost polynomial time in the original encoding. Thus VERTEX COVER is FPT despite ordinary NP-completeness.

For path $1-2-3-4$, choose vertex 2 from edge 12, then vertex 3 from edge 34. Budget two succeeds. Budget one fails because edges 12 and 34 are disjoint.

## Section 3 — Parameter-preserving reductions

An FPT reduction preserves membership, runs in FPT time, and bounds the output parameter by a computable function of the input parameter. Composition preserves FPT: output length is bounded by construction time and the target parameter factor can be bounded by a computable maximum over the allowed values.

## Section 4 — The W hierarchy

Weighted Boolean circuit satisfiability asks for exactly $k$ true input bits. Weft counts the maximum number of unbounded-fan-in gates on an input-output path; other gates have bounded fan-in. W[$t$] consists of problems FPT-reducible to weighted satisfiability with weft at most $t$ and some fixed depth bound. Imported results give FPT $\subseteq$ W[1] $\subseteq$ W[2] $\subseteq$ XP; CLIQUE parameterized by size is W[1]-complete, DOMINATING SET by size is W[2]-complete. FPT = W[1] is open. No adjacent strictness is asserted. Enumerating $k$ vertices gives CLIQUE an XP upper bound, not a lower bound.

## Exercises

1. Run the branching algorithm on a triangle at budgets one and two.
2. Prove deletion of isolated vertices preserves the answer.
3. Explain why $n^k$ is not an FPT bound as written.
4. Why does FPT CLIQUE collapse FPT and W[1], but not immediately prove P = NP?
