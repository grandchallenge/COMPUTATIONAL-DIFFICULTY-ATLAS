# C21 — Reductions Beyond Decidability

**Status:** Editorial candidate; review and figures pending.
**Prerequisites:** C05, C20.

## Question: can one impossible task explain why another is impossible?

The reduction idea survives without a time bound. We ask whether a translator exists at all.

## Section 1 — Computable many-one reductions

Fix effective encodings of machines, strings and tuples. Write $A\le_m B$ when a total computable $f$ satisfies $x\in A$ iff $f(x)\in B$. A decider for $B$ gives one for $A$ by composition; a recognizer for $B$ likewise gives a recognizer for $A$. Thus undecidability or nonrecognizability of $A$ transfers to $B$. The translator must halt even if a machine it describes never halts.

## Section 2 — Halting versus acceptance

HALT consists of pairs $(M,w)$ where $M$ halts on $w$; ACCEPT consists of pairs where $M$ accepts. Invalid encodings are outside both. Given a valid pair construct $N$ that simulates $M(w)$ and accepts if the simulation halts, even on rejection. Output $(N,\epsilon)$ without running the simulation. Map invalid strings to a fixed rejecting instance. This proves HALT $\le_m$ ACCEPT.

Conversely build $N'$ that simulates $M(w)$, halts if it accepts, and loops if it rejects. Map invalid strings to a fixed nonhalting instance. This proves ACCEPT $\le_m$ HALT. Both reductions manipulate finite code, not an answer to the source problem.

## Section 3 — RE-completeness

For any recognizable language $L$ fix its recognizer $R$. Generate a program on fixed input simulating $R(x)$ and halting only on acceptance. This is a total computable reduction to HALT. Thus HALT is RE-complete under computable many-one reductions. Its complement is not recognizable: dovetailing recognizers of both sides would decide HALT, contradicting C20. In particular the complement cannot many-one reduce to HALT.

## Section 4 — Oracle reductions

$A\le_T B$ means a machine with exact membership oracle for $B$ decides $A$, halting on every input with that oracle. Multiple adaptive queries and negation are allowed. Every many-one reduction gives a Turing reduction, but not conversely: HALT and its complement are mutually Turing reducible by one query and negation. The oracle is a formal resource, not an implementable solver.

## Section 5 — Interaction and computability

The imported MIP* = RE theorem identifies the languages admitted by polynomial-time classical randomized verifiers interacting with separated provers sharing arbitrary finite-dimensional entanglement, with constant completeness/soundness gap, with RE. This is not an ordinary halting decider: the optimal success value is a supremum over strategies without a fixed dimension bound. RE-hardness of the resulting game-value promise is not a classical time lower bound for a restricted valid-index family.
