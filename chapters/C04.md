# C04 — Verification and NP

**Status:** Manuscript draft, independent review pending.

## Question: is checking easier than finding?

A proposed solution can sometimes be checked quickly even when finding one is difficult. For a Boolean formula, a proposed truth assignment can be tested by evaluating each clause.

A language \(L\subseteq\{0,1\}^*\) belongs to \(NP\) if there exist a polynomial \(p\) and a deterministic polynomial-time verifier \(V\) such that

\[
x\in L\quad\Longleftrightarrow\quad \exists w,\ |w|\le p(|x|)\text{ and }V(x,w)=1.
\]

Here \(w\) is a *certificate* or *witness*. The two directions matter: yes-instances have some accepted witness; no-instances have none. Verification time is polynomial in the combined input length, which is polynomial in \(|x|\) because the witness is polynomially bounded.

## Worked example

For \(\varphi=(a\lor b)\land(\neg a\lor c)\), the assignment \(a=1,b=0,c=0\) satisfies both clauses. Checking the assignment takes polynomial time in the size of the encoded formula. The verifier does not need an efficient procedure to discover that assignment.

For Hamiltonian cycle, a witness is a cyclic list containing every vertex exactly once. Check that list length is correct, every vertex occurs once, and consecutive vertices (including the last and first) are adjacent. For decision TSP, also check the sum of edge weights against the given threshold.

## What is proved?

**Theorem:** \(P\subseteq NP\).

**Proof:** Let \(D\) be a deterministic polynomial-time decider for \(L\). Define \(V(x,w)=D(x)\) and choose the empty witness. The verifier meets the definition above. \(\square\)

The strict relation \(P\subsetneq NP\) is **not known**: \(P=NP\) remains an open question. NP stands for *nondeterministic polynomial time*, not *non-polynomial*. A nondeterministic machine can guess a bounded certificate and verify it; conversely, its accepting polynomial-time branch can be described by a bounded witness.

## What does not follow?

Checking one proposed tour is not the same as finding a tour, proving no feasible tour exists, or computing an optimal tour. Membership in NP alone does not establish NP-hardness or completeness.
