## Question: how can a short game require a huge search?

A game has two players. One chooses a value for a Boolean variable, the other chooses a value for the next variable, and so on. At the end, a Boolean formula decides who has won. A play lasts only as many turns as there are quantified variables, yet the number of *possible plays* can be exponential.

Can a computer decide which player has a winning strategy while remembering only the current sequence of choices and its position in the game? Yes. This example leads to **PSPACE**, the class of decision languages solvable with polynomially many work-tape cells, and to a problem complete for that class.

C09 introduced a fixed number of quantifier alternations and the polynomial hierarchy. Here the number of alternations is part of the input and can grow with its length. That change in the task contract is essential.

## Section 1 — A quantified formula describes a game

A closed quantified Boolean formula has a prefix and a Boolean matrix:

$$
Q_1x_1\,Q_2x_2\cdots Q_mx_m\;\varphi(x_1,\ldots,x_m),
$$

where each $Q_i$ is either $\exists$ or $\forall$, all variables are Boolean, and the quantifier prefix binds every variable that occurs in the matrix. **Binary input contract.** Fix an ordinary finite-alphabet grammar for parenthesized Boolean matrices built from indexed variable names, constants $0,1$, and the connectives $\neg,\land,\lor$. A binary code encodes each token and variable index unambiguously. The input represents exactly one *prenex* formula: a list of quantified variable declarations followed by one matrix expression. Every variable used in the matrix must have **exactly one** binder in the prefix; a prefix declaration may be unused, but repeated binders, free occurrences, invalid token codes, malformed parentheses or trailing data are rejected. Inputs not satisfying this contract, including arbitrary binary strings that are not valid formula encodings, are NO instances of the **total language** $\mathrm{TQBF}$. Standard reasonable explicit encodings differ only by polynomial-time translation. This choice is not a claim about every syntactically restricted QBF fragment.

We evaluate the formula from left to right. At an existential quantifier, the **existential player** chooses the corresponding bit; at a universal quantifier, the **universal player** chooses it. When all values are chosen, the existential player wins exactly when the matrix evaluates to true.

For finite perfect-information games, the quantified formula is true if and only if the existential player has a winning strategy, regardless of the universal player's choices. A strategy may choose later bits *as a function of earlier opponent choices*; it need not be one fixed assignment to all existential variables.

**Worked example A:**

$$
\forall x\,\exists y\;[(x\land y)\lor(\neg x\land\neg y)].
$$

This formula is true. After the universal player chooses $x$, the existential player chooses $y=x$, and the equality matrix is true.

**Worked example B:**

$$
\exists y\,\forall x\;[(x\land y)\lor(\neg x\land\neg y)].
$$

This formula is false. The existential player must fix $y$ before seeing $x$; the universal player can then choose $x=\neg y$ and make the matrix false. The only change between A and B is quantifier order.

These two formulas give a complete miniature example of why alternation matters.

## Section 2 — The total decision language TQBF

Let $\mathrm{TQBF}$ (also called $\mathrm{QBF}$ or $\mathrm{TRUEQBF}$ under standard conventions) be the binary language of encodings of **true, closed, well-formed quantified Boolean formulas**. Malformed encodings are rejected by convention.

Membership asks one yes/no question: is the *entire quantified formula* true? A partly assigned formula is an intermediate computational state, not an external yes-certificate in the definition of NP.

TQBF allows an arbitrary number of quantifier alternations, bounded only by the input length. The bounded-alternation truth languages from C09 are related but **not the same language**. Importantly, it would be wrong to conclude merely from this unrestricted prefix that TQBF is not in NP: strict containment between NP and PSPACE has not been proved.

## Section 3 — Direct recursive evaluator

A deliberately simple algorithm suffices to show TQBF is in PSPACE. It branches over the two possible Boolean values at each quantifier and then evaluates the fully assigned matrix.

```text
EVAL(prefix, matrix, partial_assignment):
    if prefix is empty:
        return EVALUATE(matrix, partial_assignment)
    remove first quantified variable x and its quantifier Q
    if Q is existential:
        if EVAL(rest, matrix, assignment with x=0): return YES
        return EVAL(rest, matrix, assignment with x=1)
    else:
        if not EVAL(rest, matrix, assignment with x=0): return NO
        return EVAL(rest, matrix, assignment with x=1)
```

The existential branch uses OR; the universal branch uses AND. A correctness proof follows by induction on the number of remaining quantified variables.

**Base case:** no quantified variables remain. The formula is just its Boolean matrix under a complete assignment, so the evaluator's answer is correct.

**Induction step:** suppose evaluations with fewer remaining variables are correct. At an existential node, the formula is true exactly when at least one branch is true. At a universal node, it is true exactly when both branches are true. The recursion implements those connectives on the correct subproblem answers, so it is correct.

Before evaluation, parse the input and verify well-formedness in polynomial time. Invalid encodings return NO, making the algorithm a total decider.

## Section 4 — Why recursive enumeration uses polynomial space

Let the encoded input length be $n$. There are at most $n$ quantified-variable occurrences under a reasonable explicit encoding. At a recursion depth $i$, we need to remember which quantifier is active, the current assignment bits (or changes to a shared assignment array), and enough information to continue when a branch returns.

An implementation can retain the original matrix read-only, a length-$O(n)$ assignment array, and an $O(n)$-depth recursion stack. Even a wasteful representation using $O(n)$ bits per stack frame has an $O(n^2)$ workspace bound, which is polynomial.

This is a **space** bound, not a time bound. The evaluator may visit exponentially many leaves: in the worst case, the full binary tree has $2^m$ assignments. But it does not retain all leaves simultaneously; it explores one branch, discards that branch's working state, and reuses memory.

Formally,

$$
\mathrm{TQBF}\in PSPACE.
$$

This upper bound is proved directly here from the executable recursion and its invariants. It does not by itself establish PSPACE-hardness.

## Section 5 — What PSPACE-hardness actually means

A binary decision language $H$ is PSPACE-hard under polynomial-time many-one reductions when every language $L\in PSPACE$ reduces to $H$ by a total deterministic polynomial-time function preserving answers.

TQBF is **PSPACE-complete** if:

1. its truth decision language belongs to PSPACE; and
2. every language in PSPACE reduces to it.

We proved the first claim. The second is a classical theorem requiring a genuine uniform simulation construction; a handful of quantified examples cannot establish it.

**Established theorem (imported).** Under standard explicit formula encodings, TQBF is PSPACE-complete under deterministic polynomial-time many-one reductions.

**How the succinct hardness bridge works (outline, not a full proof).** A classical route starts from the established equality $AP=PSPACE$: for each polynomial-space language, an equivalent *uniform* alternating machine has computation paths of length at most some fixed polynomial $p(n)$ on inputs of length $n$. It can have exponentially many paths, but each individual path contains only $p(n)$ computation steps and configurations of polynomial bit length. A single transition from a proposed configuration to its successor is checked by a Boolean circuit of polynomial size; iterating the fixed local transition circuit for $p(n)$ steps gives a polynomial-size verification circuit rather than an explicit tree.

Under the standard normal-form conversion that synchronizes alternating choices into fixed existential/universal levels (padding with harmless choices where necessary), **quantified choice bits** stand for the successive players' moves, with later existential bits allowed to depend on earlier universal bits. A Boolean matrix, composed uniformly from the transition circuits and a final acceptance test, evaluates the one path selected by those bits. Its quantified truth agrees with acceptance of the normalized alternating computation. The output contains $O(p(n))$ quantified decision bits together with a polynomial-size, uniformly constructible Boolean circuit representation (or an equivalent Boolean-formula construction with its size bound proved separately). **No exponentially branching computation tree is written down.**

**Proof-obligation warning:** The preceding paragraph identifies the essential ingredients but does **not** prove the uniform alternation normal form, the syntactically valid formula construction, the precise size bound when converting circuits to quantified formulas with correct dependencies, or the full many-one reduction. In particular, merely expanding a shared Boolean circuit into a formula may duplicate subcircuits exponentially, while introducing auxiliary quantified variables carelessly can change game dependencies. The standard completeness theorem is therefore **imported**; these missing uniformity and size details belong in a separate advanced proof, not in the finite game examples.

## Section 6 — The alternation theorem and the hierarchy map

Let AP denote decision languages accepted by an alternating Turing machine in polynomial time, where the computation has a polynomial-length path but may branch existentially and universally.

A classical result says

$$
AP=PSPACE.
$$

The finite-choice view makes this plausible: a polynomial-time alternating path can contain polynomially many Boolean decisions with alternating quantifiers, and a deterministic algorithm can evaluate the resulting tree using polynomial space by depth-first recursion.

**Do not confuse:** an alternating *polynomial-time path* need not mean the whole computation tree has polynomial size. In the game it is each play that is short; the set of possible plays may be immense. Alternation is a computational resource, not a free physical oracle.

C09's fixed levels satisfy

$$
PH\subseteq PSPACE.
$$

This follows from the same reuse-of-space argument applied to each fixed quantifier depth. But the equality $PH=PSPACE$ is **not known**, and one must not draw the containment as strict. TQBF's PSPACE-completeness does not prove it is outside PH, because that would require an unproved separation.

## Section 7 — Decision, strategy and witness are different outputs

The TQBF decision problem asks whether the existential player **has** a winning strategy. Finding a complete strategy is a separate search/function task. One cannot simply substitute "print the entire strategy tree" into the decision specification and assume a polynomial-size output: a full explicit strategy may be exponentially large.

In the first worked example, the strategy $y=x$ is very short. In general, strategy representations can be much more complicated. The decision problem's PSPACE-completeness concerns one output bit, not a promise that every winning strategy has a concise human-readable description.

This is the same distinction C01 introduced between decision and search tasks, now applied to an alternating game.

## Section 8 — Normal forms and encoding caveats

A formula's matrix may be written as an arbitrary Boolean expression, a circuit, or a restricted CNF or DNF, depending on the exact problem definition. Polynomial-size transformations with auxiliary variables can change the quantifier order and dependencies, so an encoding conversion must not be assumed to preserve quantified truth automatically.

**In particular:** a fixed prefix $\exists X\,\forall Y$ with a CNF matrix is not the canonical generic $\Sigma_2^P$-complete truth problem. As C09 shows, the universal clauses can be simplified to an ordinary SAT problem. The full TQBF problem permits *unbounded* quantifier alternations; its completeness status does not automatically transfer to arbitrary restricted fragments.

A classroom description such as “QBF is PSPACE-complete” therefore refers to the **standard unrestricted truth language** unless an exact fragment and representation are given.

## Section 9 — What has and has not been established

- We have given a direct polynomial-space algorithm for deciding true quantified formulas.
- We have used a published PSPACE-hardness theorem for TQBF; we have **not** reproduced the full uniform reduction here.
- We know $P\subseteq NP\subseteq PSPACE\subseteq EXPTIME$.
- We know $P\subsetneq EXPTIME$ by the time hierarchy theorem, but **do not** know $P\ne PSPACE$ or $NP\ne PSPACE$.
- We know PSPACE-complete decision problems exist, but their completeness does not determine which unknown adjacent inclusions are strict.

The distinction between a proved simulation, a cited completeness theorem, and an open separation must remain legible in every subsequent Atlas figure.

## Map update

The Atlas now introduces a **game/strategy interpretation** of PSPACE: polynomially many memory cells can support exploration of an enormous but finitely branching tree, provided the search reuses its workspace. The quantifier-alternation axis from C09 connects to the space axis from C10 through the classical $AP=PSPACE$ theorem.

The class inclusion $PH\subseteq PSPACE$ is known. The strictness of this inclusion is not. TQBF is complete for PSPACE; the source of this hardness is a cited, established uniform simulation theorem, not the toy equality game.
