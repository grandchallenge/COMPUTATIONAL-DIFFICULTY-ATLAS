# C04 — Verification and NP

Status: keystone specification v0.1

## Pedagogical objective

The reader should acquire the witness-verifier mental model of NP and understand exactly what "efficiently checkable" does and does not mean.

## Reader-facing question

Can a proposed yes-answer be accompanied by a short certificate whose validity can be checked efficiently?

## Core distinctions

- solving vs verifying;
- yes-instances vs no-instances;
- witness length vs input length;
- verifier runtime vs search runtime;
- informal plausibility vs a formal polynomially bounded certificate relation.

## Anchor problems

- **SAT:** primary anchor; a satisfying assignment is the witness.
- **Hamiltonian cycle:** a listed cycle is the witness.
- **TSP decision:** a tour at most a stated bound is the witness.
- **Factorization:** used cautiously to show that efficient verification alone does not imply NP-completeness.

## Formal payload

Define NP via a polynomial-time verifier:

For a language \(L\), there exist a polynomial \(p\) and polynomial-time predicate \(V\) such that

\[
x \in L \iff \exists w,\ |w|\le p(|x|)\ \text{and}\ V(x,w)=1.
\]

Then connect, at proof-sketch level, to nondeterministic polynomial time.

Establish \(P \subseteq NP\). Do not imply the containment is known strict.

## Misconception obligations

M01, M16, M04 foundations.

## Figure obligations

- verifier pipeline: instance + certificate -> verifier -> accept/reject;
- side-by-side SAT yes-instance and unsatisfiable-instance asymmetry;
- F1.1 map update highlighting \(P \subseteq NP\) with equality open.

## Epistemic-status requirements

"P vs NP is open" must appear wherever the containment geometry could be read as strict.

## Exercises / thought experiments

1. Specify a verifier and witness bound for Hamiltonian cycle.
2. Explain why checking a proposed certificate is not the same as finding one.
3. Spot the defect in "NP stands for non-polynomial."
4. Give an example where a certificate that is correct in spirit is too long to satisfy the NP definition.

## Map update

The reader adds verification as a distinct computational notion and understands NP as a class defined by bounded witnesses, not as a synonym for "hard."

## Exit test

The reader can state NP using a verifier and explain SAT as an instance of the definition.
