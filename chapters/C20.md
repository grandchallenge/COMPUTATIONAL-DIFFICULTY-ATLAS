# C20 — The Boundary of Computability

**Status:** Manuscript candidate, not yet independently reviewed.

## Question

Is every precisely stated decision problem solvable by an algorithm that always halts? No. An unsolved efficiency question asks how much time or memory a procedure needs. An **undecidability** theorem says no total correct procedure exists for the stipulated computational model.

A language is **decidable** when some Turing machine halts on all inputs and correctly determines membership. A language is **recognizable** when a machine accepts all members and no nonmembers, but may run forever on nonmembers.

## Example: halting

Fix an effective encoding of a machine M and input x. Define the halting language as the language \(HALT=\{\langle M,x\rangle:M\text{ halts on }x\}\). This language is recognizable: simulate M(x) and accept if it stops.

**Theorem.** The halting language is undecidable.

**Proof.** Suppose a total correct algorithm \(H(M,x)\) determines whether machine M halts on input x. Define machine D as follows: on input encoding y, ask \(H(y,y)\); if it predicts halting, loop forever, and if it predicts nonhalting, stop. Let d be D's encoding. Then \(D(d)\) halts exactly when \(H(d,d)\) predicts it will not halt, contradicting correctness in either case. Hence H does not exist.

The proof concerns a universal decider for **all** encoded pairs, not our ability to establish termination of any particular program.

## Decidable and recognizable

**Theorem.** A language is decidable if and only if both it and its complement are recognizable.

**Proof.** A decider can be used to recognize either set, reversing the answer for the complement. Conversely, alternate steps of recognizers for a language and its complement; one must eventually accept, supplying a terminating correct decision. Thus the complement of the halting language is not recognizable.

## Contrast with SAT

A Boolean formula with n variables has finitely many assignments. Testing all of them always terminates, so SAT is decidable, even though its polynomial-time solvability remains open. “Could take exponentially long” is categorically different from “has no total decider.”
